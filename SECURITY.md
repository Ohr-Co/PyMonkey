# Security

PyMonkey runs your Python scripts with access to the pages you allow, so a flaw in it can expose what you see and do on those sites.

## Reporting a problem

Please do not open a public issue for a security problem. Report it privately instead: on the repository's **Security** tab, choose **Report a vulnerability** (GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)). Only the maintainers see the report.

Say what an attacker can do, and how: the steps, a script or page that shows it, and the Chrome and PyMonkey versions. You will get an answer within a week. Once a fix is out, the advisory is published, with your name if you want it.

## Supported versions

Only the latest version on `main` gets fixes.
